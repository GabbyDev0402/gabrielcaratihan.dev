# Gabriel Caratihan - Enterprise Software Engineering Portfolio

A high-converting, enterprise-grade Software Engineering Portfolio built with **Next.js (App Router)**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide React**.

## 🛠️ Tech Stack & Features

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4, Glassmorphism UI
- **Animations**: Framer Motion scroll (`whileInView`) & Modal (`AnimatePresence`)
- **PDF Resume**: Auto-generated multi-page resume PDF with project screenshots
- **Email System**: Pre-templated mailto composition engine & Gmail webmail Compose fallback

## 💻 Getting Started Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📄 Build & Production

```bash
npm run build
```
